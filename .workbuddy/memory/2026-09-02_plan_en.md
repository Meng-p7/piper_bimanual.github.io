## 3. Content Principles (apply to every section)

- **Completed / In-Progress / Future** pills in every card. Colors come from new tokens.
- **No fabricated numbers**: success rates, confidence intervals, camera resolutions, mechanical specs never appear unless ACT-main has them.
- **Real materials first**: every media slot uses `media-placeholder` + `TODO` comment so replacement is obvious.
- **Sub-section locator**: kicker with mono numbering on every heading.
- **Quote / note beats**: in §02 / §07 / §09 / §13, drop a mono "lab note" callout instead of an academic citation — keeps rhythm lively.
