# Piper 双臂毛巾折叠 — 项目主页刷新 Plan (2026-09-02)

## 1. 项目背景 & 设计目标

- **当前网站**：第一版面向"通用双臂机器人平台"，主要介绍 Pick Bread + 200 条示教 + ACT/SmolVLA + 原厂/自研夹爪对比 + NUC→RK3588S 迁移，**几乎所有数字都是"待进行"占位**。
- **真实进展（截止 2026-09-02）**：项目主线已切换到 **bimanual towel folding**，并形成一套 **课程式 HIL 微调** 流程：
  - C0 管线与失败诊断（08-26 ~ 08-29）—— 完成
  - C1 直接抓角基础策略（100 episodes, Orbbec+双腕, ACT@20k）—— 完成
  - C2 困难状态人工接管数据采集（101 episodes, 54,791 frames）—— 完成
  - C3 继承微调（从 C1 初始化，HIL 上 10k steps）—— 完成
  - C4 定性整任务测试 —— 通过（红、绿毛巾均能完成抓起到折好）
  - C5 定量验收（base20k / scratch10k / finetune10k 36-trial 配对筛查 + 45-trial 验收）—— 待 2026-09-03 执行
- **架构 & 代码**：`https://github.com/dream25851/physical_ai_runtime`（Pixi + ROS 2 Jazzy + ownership-based src/ + Embodiment + RMI Python SDK + Episode Recorder + teleop/recording/motion_planning 子仓库 + `lerobot` env for training）。
- **设计目标**：
  1. **学术展示 + 简历可用**：30 秒讲清楚"我做了什么、为什么这样做、做到了什么程度"；
  2. **真实优先**：所有数字、所有事实都从 ACT-main 实测记录或 prompt v2 中来，不发明论文/成功率/算法贡献；
  3. **节奏不死板**：保留学术模块化的同时，在"课程管线""工程心得"等节点引入叙事化的笔记段落，避免成为纯参数清单；
  4. **中英双语**：英文为主入口，中文为镜像，章节顺序与术语一一对齐。

## 3. 内容原则（每个章节都遵守）

- **Completed vs In-Progress vs Future**：每张卡都标 status pill（绿勾 / 橙时钟 / 蓝未来），颜色用现有 token（accent / warn / blue）。
- **No fabricated numbers**：成功率、置信区间、相机分辨率、机械规格不写具体数字，除非 ACT-main 里有真实记录。
- **Real materials first**：所有图位用 `media-placeholder` + TODO 注释，方便日后替换为真实视频/截图。
- **Sub-section 一句话定位**：每个二级标题前加 kicker（mono 字 + 编号），便于扫读。
- **Quote / 笔记穿插**：在 02 / 07 / 09 / 13 用 mono 字体的"工程笔记 callout"代替学术引文，让节奏更活。
